What this tool does

This tool turns a deal's business materials and financial model into a Monte Carlo-simulated LBO view an IC can actually interrogate, instead of a single hand-picked base/upside/downside case.

How it works, end to end:

  1. Ingest a deck/CIM and the Excel model.
  2. Get a first-pass variable card -- P10/P50/P90 ranges, correlations, and binary risk events for whatever actually drives this deal.
  3. Challenge and edit the card in conversation, then confirm it.
  4. Pull a base-case financial spine (revenue, gross profit, EBITDA, levered FCF, exit) straight from the model -- no invented numbers.
  5. Check the deterministic LBO mechanics (entry/exit, debt paydown) tie out to the real Excel model, and fix any assumption that doesn't.
  6. Run a 10,000-path Monte Carlo simulation and export an IC-ready slide.

Save your work as a project at any point and come back to it later -- nothing is lost between sessions.
